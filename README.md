# 🚗 BMW Website

A sleek, modern, and fully responsive BMW-inspired web application built using **HTML5, CSS3, and JavaScript**. This project showcases interactive BMW vehicle displays, video reels, light/dark mode toggling, and a seamless user interface.

---

## 🌟 Features

* **Responsive Navigation:** Interactive navigation menu optimized for mobile, tablet, and desktop viewports.
* **Hero Section:** Eye-catching landing showcase featuring key call-to-action (CTA) buttons.
* **BMW Models Showcase:** Detailed presentation of popular models (M4, X5, 7 Series, etc.).
* **Video Reels Section:** Engaging media display section for BMW promos and visual edits.
* **Theme Switcher:** Dynamic Dark/Light mode toggle for tailored user experience.
* **Smooth Animations & UI Effects:** Seamless transitions and smooth scrolling navigation.
* **Interactive Elements:** Back-to-Top dynamic button, contact modal/form, and social links.
